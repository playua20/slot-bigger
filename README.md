# 🎣 Bigger Bass Splash — iGaming Prelander (Pet Project)

A minimal fake-slot prelander inspired by iGaming funnels (casino / free spins).  
Built without frameworks — focused on layout precision, aspect-ratio handling, and animated UI.

🔗 **Live Demo:**  
https://bigger-bass-splash.vercel.app/

## 🧩 Features
- Fixed aspect ratio (1080 / 1945)
- Fullscreen wrapper with center alignment
- Slot-style UI (logo, reels, fake spin, win overlay)
- Custom fonts & CSS animations

## 🛠 Tech Stack
- **HTML / CSS / Vanilla JS**
- **Google Fonts (Titan One / Changa One)**

## 🎯 Purpose
UI experiment & portfolio piece for iGaming-style landing flows.
